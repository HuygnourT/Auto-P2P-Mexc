  1. Mở Telegram, chat với @BotFather → gõ /newbot → đặt tên → nhận Bot Token.
    2. 
            
  2. Chat với @userinfobot để biết User ID của bạn.
    3. 
            
  3. Chat riêng với bot: Chat ID = User ID. Dùng trong nhóm: thêm bot vào nhóm, Chat ID của nhóm là số âm (vd -100…).
    4. 
            
  4. Bấm Lưu & áp dụng, rồi Kiểm tra kết nối. Mở bot, gõ /menu.
    5. 
          

          
Bot chỉ trả lời đúng User ID + Chat ID ở trên; mọi người khác bị từ chối. Bot chạy cùng app trên máy này (không cần domain) — tắt app thì bot cũng tắt.
